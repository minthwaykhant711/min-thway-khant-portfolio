# Min Thway Khant — Engineering Portfolio

A responsive static portfolio for internship and future job applications.

## Included
- Professional portfolio homepage
- About, projects, technical skills, achievements, credentials and contact sections
- Project screenshot galleries with keyboard navigation
- Resume and certificate links
- Mobile navigation and responsive layouts
- No build step required

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Publish
The folder can be deployed to GitHub Pages, Netlify or Vercel as a static site.

## Notes
The portfolio content is based on the resume, project screenshots and information provided for the portfolio. Project screenshots are kept local in `assets/projects/`.
